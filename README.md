## 🚀 Projets principaux

### 🔄 [BIflow](https://github.com/NourEsprit123/BIFlow) : automatisation du pipeline BI par l'IA
Solution qui automatise l'ensemble du pipeline de Business Intelligence grâce à une **architecture multi-agents**, avec une interface web interactive.

- Orchestration de plusieurs agents IA spécialisés
- Dashboard interactif, visualisation et analyse automatisée des données
- Machine Learning et **Explainable AI (XAI)** pour des résultats compréhensibles
- RAG pour interroger la connaissance métier

`Python` `Streamlit` `Pandas` `NumPy` `Scikit-learn` `Plotly` `SQL` `Multi-Agent AI` `RAG` `XAI`

### 🛒 [Visual E-Commerce Return & Refund Auditor](https://github.com/NourEsprit123) : audit intelligent des retours et remboursements
Le client envoie un numéro de commande, une description du problème et une photo du produit. Trois agents spécialisés traitent la demande :

| Agent | Rôle |
|---|---|
| 🖼️ **Multimodal** | Analyse la photo, identifie le produit et les dommages |
| 📚 **RAG** | Consulte la base de connaissances pour vérifier la politique de retour applicable |
| ⚖️ **Evaluator** | Décide **APPROVED** ou **ESCALATED**, avec des guardrails contre les décisions risquées |

Le processus de vérification est orchestré par un workflow automatisé.

`Python` `Streamlit` `Google Gemini API` `Pydantic` `SQLite/PostgreSQL` `n8n` `VLM` `LLM` `RAG` `Computer Vision`

### 🤖 [SmartDoc AI](https://github.com/NourEsprit123/SmartDoc) : plateforme intelligente d'analyse de documents *(projet personnel)*
Application web qui permet de gérer, analyser et **interroger ses documents grâce à l'IA générative**, avec une architecture **RAG** (embeddings + LLM) : l'utilisateur pose des questions directement sur le contenu de ses documents.

- Téléversement de documents et extraction automatique du contenu
- Découpage en chunks, génération d'embeddings (Sentence Transformers) et stockage dans **ChromaDB**
- Recherche sémantique et réponses contextualisées générées par un LLM (**Groq**)
- Génération automatique de résumés
- Gestion et authentification des utilisateurs, consultation des documents enregistrés

`Python` `Django` `ChromaDB` `Sentence Transformers` `Groq` `LLM` `RAG`
